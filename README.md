# 週イチ体重

体重を週1回入れるだけの記録ページです。`index.html` をブラウザで開くと使えます。サーバー、ビルド、依存パッケージはありません。

- 1週間（月曜はじまり）に1件だけ記録し、同じ週に入れ直すと上書きします。
- 記録はブラウザの `localStorage`（キー `weekly-weight-v1`）の中だけに保存し、外部へ送信しません。
- バックアップは JSON ファイル（`weekly-weight-YYYY-MM-DD.json`）で保存と読み込みができます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面と CSS |
| `core.js` | 計算、検査、保存の読み書き（DOM なし。Node からも読める） |
| `app.js` | 画面の描画と操作 |
| `core.test.js` | `core.js` の単体テスト |
| `source.test.js` | 画面に載せない語、外部送信、`confirm()` がないことの確認 |

## テスト

Node.js 22 以上で、このフォルダから次を実行します。

```
node --test
```
